# SkyPro_Project_4
## "Сервис рассылок"

### Основная информация

* Framework - Django
* База данных - postgreSQL
* CSS - Bootstrap
* Кэш - Redis

### Команды

1. `python init_db.py` - создать базу данных
2. `python manage.py run_newsletter {newsletter_id}` - запустить рассылку через CLI

### Приложение `newsletters`

* Позволяет создавать рассылки, сообщения, получателей.
* Ограничения доступа.
* Кэширование 'тяжёлого' контекста

### Приложение `users`

* Обеспечивает основные функции пользователей: аутентификация, подтверждение, восстановление пароля.
* Предоставляет модератору доступ к блокировке пользователей.
